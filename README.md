# E-Commerce Customer Behavior and Purchase Patterns Analysis

## Project Overview
This project analyzes customer behavior and purchase patterns for an online store using Exploratory Data Analysis (EDA) and an interactive Streamlit dashboard.

## Key Findings
1. **Membership Duration is Key:** Length of membership has the strongest positive correlation with yearly amount spent.
2. **Mobile App Engagement:** Customers spending more time on the mobile app tend to have higher yearly spending compared to the website.
3. **Consistent Session Length:** Average session length remains consistent across customers around 33 minutes.
